# 质量点检清单

一个单机版的质量点检记录工具。双击 `index.html` 即可在浏览器中使用，不需要安装、不需要联网、不需要服务器。

## 用途

车间班次开工前，按固定项目逐项点检，记录判定结果与异常备注。数据自动保存在本机浏览器中，刷新或关闭页面不会丢失。

## 功能

- 6 项标准点检内容（外观 / 关键尺寸 / 装配 / 标识 / 包装 / 功能）
- 逐项判定：合格、不合格、免检（免检不计入合格率）
- 每项可填写异常备注
- 自动计算合格率
- 输入内容即时保存到浏览器本地存储
- 支持浏览器打印

## 使用方法

1. 解压或克隆到任意目录
2. 双击 `index.html`
3. 填写日期、批次号、点检人
4. 逐项点击判定按钮
5. 需要纸质记录时按 `Ctrl + P` 打印

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面结构 |
| `style.css` | 样式与打印排版 |
| `app.js` | 点检逻辑与本地存储 |

## 自定义

修改 `app.js` 顶部的 `CHECK_ITEMS` 数组即可调整点检项目：

```js
const CHECK_ITEMS = [
  { id: 'c1', name: '外观', standard: '表面无划伤、碰伤、毛刺、油污' },
  // 按同样格式继续添加
];
```

`id` 必须唯一且不要随意改动，否则已保存的历史记录会对不上。

## 注意事项

- 数据保存在**当前浏览器**的本地存储中。换浏览器、换电脑、清理浏览器数据都会丢失。
- 如需多人共用或长期归档，请将记录导出后另行保存。
